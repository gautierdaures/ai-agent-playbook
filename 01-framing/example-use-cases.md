# Example use cases

## Bibliographic research assistant

A worked example from the training:

- Ask the user about their challenges and what they work on, so the agent knows which tools and sources to trust.
- Build a graph of relationships, between articles and between researchers.
- Recommend with a reason: "I recommend X because you work on Y."
- Personalize by user profile, not just by object or query. Add context to the search so it fits the person.

This leans on [RAG and a knowledge graph](../03-build/rag-and-tooling.md).
